. Interactive Testing via Swagger UI & ReDoc
FastAPI automatically generates interactive API documentation for testing endpoints in the browser:

Start the local development server:
uvicorn app.main:app --reload
python -m app --reload

powershell
cd d:\Projects\Marketing_in_a_box\application\backend
.\.venv\Scripts\python.exe -m app --reload
# Port 8001 — that's what the frontend's Vite proxy points /api/* at.
# Use `python -m app`, NOT `uvicorn app.main:app`. Two separate traps with that one:
#   1) PORT: uvicorn defaults to 8000, the Vite proxy calls 8001 — so every /api/* request fails
#      at the proxy and the UI says "Couldn't load chat history" while /health on 8000 looks fine.
#      (If you must use uvicorn directly, add --port 8001.)
#   2) EVENT LOOP: on Windows a single-process uvicorn builds a ProactorEventLoop, which psycopg's
#      async mode refuses, and then every DB route 500s while /health and /docs still answer 200.
# See application/backend/README.md.
# Only ONE server at a time on a port — Windows lets a second uvicorn bind the same port and
# then stale code answers the requests (this is what silently emptied the chat-history sidebar).
Open in your browser:

Swagger UI (Interactive): http://127.0.0.1:8001/docs (allows you to send requests and inspect responses directly)
ReDoc (Reference): http://127.0.0.1:8001/redoc
