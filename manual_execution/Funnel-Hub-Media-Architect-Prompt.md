# FUNNEL HUB & MEDIA ARCHITECT — INPUT-DRIVEN PROMPT

A three-phase master prompt for mapping the 18 canonical funnel types onto any client's service line, in three progressively deeper structures: media-fit grouping, a convergent "hub" model, and a customer-commitment ladder. Industry-agnostic — fill in the INPUTS block for any client, vertical, or service.

- **Established buyer personas (if any):** [YOUR ANSWER — name and one-line role for each; if none exist yet, note that personas must be inferred from the reference material before proceeding]
- **Primary conversion action (if one already exists):** [YOUR ANSWER — e.g. an existing "book a call" or "start a trial" CTA already in use, so new funnels don't duplicate it]

**The 18 funnel types (fixed taxonomy, used across all three phases):**
Lead Magnet / Squeeze Page, Reverse Squeeze Page, Survey Funnel, Tripwire / SLO Funnel, Free-Plus-Shipping / Book Funnel, Cart Funnel, VSL / Sales Letter Funnel, Product Launch Funnel, Challenge Funnel, Webinar Funnel, Summit Funnel, Application Funnel, Membership Funnel, High Ticket Funnel, Consultation Funnel, Free Trial Funnel, Evergreen Funnel, Quiz Funnel.

## PHASE 1 — MEDIA FIT, TOPIC MAPPING & PURCHASE-INTENT RANKING

1. **Group all 18 funnel types by acquisition media** — Organic, Paid, or Both — based on the mechanics of each funnel type, not on where it could theoretically ever appear. State the reasoning for each: does the funnel's economics, format, or traffic-source need favour organic content/SEO, paid ad spend, or work equally for either?
2. **Map every funnel type to a real topic and offer for [Service / product line], grounded in the reference folder.** Each mapping should name: the specific topic or content asset it uses, what the funnel actually contains (steps, screens, or content sequence), and one to two offer headlines.
3. **Design the result as an interactive HTML mindmap** with expandable/collapsible nodes. Structure: a root node, branching into the three media categories (Organic / Both / Paid), each expanding to its member funnels; clicking a funnel node reveals its topic, content details, and offer(s). Reuse the client's existing design tokens (colours, type, button/card styles) rather than inventing a new visual system.
4. **Deliver a companion Word document** containing the full media-fit grouping (with reasoning), the topic/content mapping for all 18 funnels, and a ranking of all 18 funnels by closeness to purchase intent — i.e. how far along a visitor already is toward being ready to transact when they enter that funnel type, independent of how large the funnel's ask is. Give a one-to-two-sentence reason for every rank.

---

## PHASE 2 — THE CONVERGENT HUB MODEL ("ALL ROADS LEAD TO ROME")

Restructure the same 18 funnels — and the offers/headlines built in Phase 1 — into a hub model:

1. **Entry and nurture stages carry multiple funnels.** The first two or three funnel stages (top-of-funnel and middle-of-funnel) should each contain several different funnel types, built for different audiences, formats, or channels.
2. **All of them converge into a single convert stage carrying only one or two main offers.** This is the "Rome" every road leads to.
3. **Post-conversion, multiple funnels/offers cascade as upsells and cross-sells** across one or more subsequent stages, forming a visible hub-and-cascade shape rather than a single straight-line funnel.
4. **Visualise the hub** — a diagram showing the many-to-few convergence into the convert stage, followed by the upsell/cross-sell cascade.
5. **Layer in three new metrics on every funnel/offer:**
   - **Ease of Implementation** — a simple score (e.g. 1–5) for how much build effort the funnel requires before it can run.
   - **Time Decay + Effort** — is the underlying topic/funnel/offer a temporary or viral asset (short shelf life, needs refreshing) or an evergreen one (durable, reusable indefinitely for the agency), cross-referenced against how much production effort it took to build (Low/Medium/High).
   - **Audience Awareness Level** — classify each funnel/offer along Unaware → Problem-Aware → Solution-Aware → Product-Aware → Most-Aware.
6. **Cross-map awareness level against relevance-by-role**, split roughly 50% business owners / 30% reviewers or coordinators / remainder technical or implementation stakeholders (adjust the named roles to whatever buyer personas exist for this client — if a technical/implementation-focused role doesn't already exist as a named persona, define it as a lightweight overlay rather than inventing a full new persona).
7. **Deliver a new Word document** presenting the hub model — visualised, staged, and populated with the topics/offers/headlines from Phase 1 — with all three new metrics attached to every funnel.

---

## PHASE 3 — THE LOW-TICKET-TO-HIGH-TICKET COMMITMENT LADDER

Re-group the same 18 funnel types a second way — by **customer commitment**, not media or funnel stage:

1. **Order all 18 funnels from lowest to highest commitment**, judged from the customer's point of view: what are they being asked to give up to enter this funnel — an email address, a few minutes, personal/business details, real money, real time, or some combination? (Reference example: a Lead Magnet Funnel asks only for an email; a Summit Funnel asks for contact details *and* a real time commitment — that is a higher-commitment ask even though no money changes hands.)
2. **For every funnel in the ladder, supply two to three concrete offers**, each with its own headline and one-line description.
3. **Tag every offer with the same metrics introduced in Phase 2**: Time Decay + Effort, Audience Awareness Level, and the owner/reviewer/technical relevance split.
4. **Deliver this as an interactive HTML design only** — no Word document for this phase. Visualise the ascending commitment scale (e.g. a ladder, staircase, or ordered scale) with expandable detail per funnel, reusing the client's established design tokens.

---

## Notes for whoever executes this prompt

- Phases build on each other — Phase 2 and 3 should reuse the topic/offer work from Phase 1 rather than inventing a second set of offers from scratch, unless the commitment re-grouping in Phase 3 genuinely calls for different offers at that ask level.
- This taxonomy and structure is service- and industry-agnostic by design — the same 18 funnel types, media grouping, hub model, and commitment ladder apply whether the service being mapped is a marketing service, a SaaS product, an e-commerce brand, a professional-services practice, or any other business line. Only the topics, offers, headlines, and grounding documents should change per client/service.
- Where the client's existing strategy documents reference assets as already built that cannot be located as real files, flag this explicitly rather than silently assuming they exist.
